HOW TO USE CMD(COMMAND PROMT)
-CD.. ----> USED TO GO BACK ONE FOLDER(DIRECTORY)
-CD --> MEANS CHANGE DIRECTORY.
-MKDIR --> MEANS MAKE NEW DIRECTORY(FOLDER)
-TYPE NUL > NAME.PY OR .IPYNB --> MEANS USED TO CREATE A FILE
-TOUCH --> HELP TO CREATE NEW FILE. WORKS IN WINDOWS 10 BUT NOT SUPPORTED IN WINDOWS11.
